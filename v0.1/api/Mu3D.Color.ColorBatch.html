Converts each source coordinate and writes the corresponding destination prefix.

Source coordinates; an empty span is accepted.

The conversion implementation; reference-type implementations cannot be null.

Type Parameters

TSource

The source coordinate value type.

TDestination

The destination coordinate value type.

TTransform

The statically selected CPU transform implementation.

Remarks

The method allocates no output storage and uses constrained generic calls, without a per-coordinate delegate or boxing when TTransform is a value type. The transform is passed by value; a value-type implementation is copied once for this call. Any allocations made by a custom transform remain its own responsibility. Only the first source.Length destination elements are written, leaving any destination tail unchanged. Source and the written destination prefix may overlap only when their element types and starting locations are identical. That exact in-place case reads each element before writing its result. Other overlap is rejected before conversion begins. Conversion is not transactional: if the transform throws, earlier results remain written. Metadata and conversion policies are supplied by coordinate values and the transform, not this loop.

Exceptions

ArgumentException

Destination storage is too short or overlaps source in an unsupported way.

ArgumentNullException

A reference-type transform is null.
