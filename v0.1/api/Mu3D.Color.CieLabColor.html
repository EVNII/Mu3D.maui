Remarks

D50 uses xy = (0.3457, 0.3585) with reference Y = 1. Lightness normally spans zero to 100; extended lightness and opponent coordinates are retained without clipping. This is a relative color representation, not an absolute HDR luminance or viewing-conditions model.
