Remarks

Working linear RGB is rendered to the proof device, then decoded with ICC-absolute intent so paper/media white and black are retained. It can be returned in a standard linear RGB space or rendered into an optional display ICC profile. The source is never changed. Only the existing supported RGB ICC profile types are accepted; CMYK and spectral printer models are unsupported. Clipping flags report explicit encoded-boundary clamping, not gamut mapping inside profile LUTs. Black-point compensation is confined to the initial working-to-proof rendering; it is not reapplied to the subsequent absolute paper/black simulation. A non-absolute display intent explicitly requests further display rendering and may change the simulated appearance. HDR tone mapping and conversion of scene exposure into print-relative light are caller-owned.
