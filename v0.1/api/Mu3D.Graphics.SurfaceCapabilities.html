IReadOnlyList<SurfaceFormatCapability>

Remarks

An empty list means that the backend exposes only format capabilities. It does not mean that every format supports every color encoding. Mu3D's pinned wgpu-native v29 backend uses this legacy form; a future backend with paired capability reporting populates this list.
