Rgba16FloatTextureCreated bool

Whether a real RGBA16Float texture was created.

CubeArrayTextureShaderCompiled bool

Whether a minimal cube-array sampling shader validated on the created device. False on devices whose backend wrongly withholds the cube-array downlevel flag (for example Apple devices whose Metal driver no longer answers the deprecated MTLFeatureSet query wgpu relies on).

MaxSampledTexturesPerShaderStage uint

The device limit for sampled textures per shader stage, or zero when the limit query failed.

SurfaceProbed bool

Whether this result includes surface negotiation.
