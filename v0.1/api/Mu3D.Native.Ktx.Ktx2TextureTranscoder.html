Transcodes glTF-compatible KTX2 Basis Universal textures through pinned Khronos libktx. The adapter owns no GPU resource and copies the selected compressed mip chain into Mu3D's backend-independent immutable material representation.

Parameters

allowBt709PrimariesForLinearData bool

True to tolerate BT.709 primaries on linear non-color data. Khronos KHR_texture_basisu requires unspecified primaries, so this is intended only for known legacy assets; the transfer function must still be linear.
