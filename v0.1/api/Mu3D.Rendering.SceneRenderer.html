Class SceneRenderer

Namespace
Mu3D.Rendering
Assembly
Mu3D.Core.dll

Renders visible unlit, directly lit and image-lit meshes through the backend-independent graphics API and caches immutable geometry, environments and per-mesh bindings. This renderer is not thread-safe.

PrepareImageBasedLightingAsync(EquirectangularHdrEnvironment, CancellationToken)

Precomputes and process-caches the renderer's diffuse and specular image-based-lighting data without creating GPU resources. Applications may await this off the presentation path so the first rendered frame only uploads the immutable result. The cache is released when the source environment is no longer referenced.
