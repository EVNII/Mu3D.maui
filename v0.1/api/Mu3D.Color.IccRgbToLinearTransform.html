Remarks

Media-relative matrix/TRC, legacy lut8Type/lut16Type, ICC v4 lutAToBType, and RGB-to-PCS multiProcessElementsType transforms with bounded one-to-sixteen-channel intermediate elements are supported. ICC-absolute input is supported when the profile supplies a direct D2B3 transform. Otherwise it is synthesized from the media-relative transform and mediaWhitePointTag. Black-point compensation remains an explicit unsupported path.
