TryNavigate(Vector2, Vector2, float)

Attempts one atomic application-supplied composite navigation delta.

public bool TryNavigate(Vector2 rotationRadians, Vector2 panViewportDelta, float dollyDelta)

Parameters

rotationRadians Vector2

The signed yaw/pitch delta in radians. Positive X rotates right and positive Y rotates down.

panViewportDelta Vector2

The signed viewport-relative pan delta. Positive X pans right and positive Y pans up.

dollyDelta float

The signed logarithmic dolly delta; positive moves inward.

Returns

bool

True when the attached controller accepted at least one non-zero component.

Remarks

Applications that own held-key or gamepad state can normalize simultaneous axes, multiply them by elapsed time and submit one delta per VSync frame. The complete delta uses one camera-priority arbitration lease, so diagonal input cannot be split by another tool.
