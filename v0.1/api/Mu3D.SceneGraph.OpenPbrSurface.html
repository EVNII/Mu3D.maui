Remarks

Defaults and parameter identities follow the pinned OpenPBR v1.1.1 reference nodedef. Color3 values carry linear-light metadata and alpha one; signed and extended-range authoring values are retained without implicit gamut mapping. Numeric bounds follow the nodedef's hard scalar bounds, not its soft UI bounds. Geometry vectors default to inherited world-space normal/tangent semantics. Graph connections are immutable and override the associated constants.
