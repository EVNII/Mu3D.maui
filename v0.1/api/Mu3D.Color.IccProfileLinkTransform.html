Remarks

Black-point compensation is optional and explicit. When supplied, it follows the ICC/ISO media-relative neutral-axis scale-and-offset procedure. Use CreateWithAutomaticBlackPointCompensation(IccProfile, IccProfile, IccRenderingIntent) to estimate the RGB profile black points with IccBlackPointEstimator before creating the link.
