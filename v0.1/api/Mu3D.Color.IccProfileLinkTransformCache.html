Remarks

Cache identity includes the exact immutable source and destination profile instances, their fingerprints, rendering intent, and disabled, explicit, or automatic black-point-compensation policy. Using instance identity preserves the profile objects exposed by cached transforms and returned encoded colors. ICC PCS D50 handling and chromatic adaptation are defined by the full profile payload represented by each fingerprint. The cache is thread-safe and caller-owned; it does not retain profiles in a process-wide static cache.
