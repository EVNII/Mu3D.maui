Remarks

The pass loads HDR-linear scene color and depth, writes no depth, and uses premultiplied-alpha blending. The borrowed helper remains independent of scene bounds, selection, and export. The pass reuses bounded, value-only vertex staging while reevaluating the current helper, camera, and physical output extent on every execution. Disposal releases the staging capacity together with the graphics resources.
