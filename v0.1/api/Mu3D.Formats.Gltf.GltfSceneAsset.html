Remarks

Immutable geometry and decoded or compressed texture sources are shared. Nodes, transforms, materials, skins, morph weights, animation targets and active material-variant selection are independent for every instance. This managed definition owns no renderer, surface or native GPU resource and can therefore supply instances to different application scenes or scene views.
