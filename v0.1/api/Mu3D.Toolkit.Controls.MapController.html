Remarks

Panning is constrained to the plane perpendicular to WorldUp, and the default polar constraint keeps the camera on or above that plane. The controller is UI-independent: a host decides which mouse, touch, pen or keyboard input produces each command. The camera and optional frame requester are borrowed.
