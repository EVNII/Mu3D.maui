Remarks

Results contain the closest triangle from each intersected mesh and are ordered by increasing camera distance. This class determines geometric intersections only; it does not choose a selection, acquire input, mutate scene nodes, or own the scene or camera. Each request applies current FP32 morph position deltas in target order before rigid world transformation, matching the renderer's morph stage. Skin deformation and material alpha masks are not evaluated. Results use current scene state, not a snapshot of a previously presented frame.
