Remarks

These are geometric RGB coordinates, not perceptually uniform lightness or saturation. Only the sRGB encoding corresponds to CSS HSL. Hue is canonicalized to [0,360) degrees; saturation, lightness and alpha are in [0,1]. HDR or out-of-gamut RGB needs explicit mapping first.
