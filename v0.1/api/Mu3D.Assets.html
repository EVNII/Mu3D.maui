Namespace Mu3D.Assets

Classes

SceneAsset

Captures a reusable backend-independent scene resource from which independent mutable scene instances can be created.

SceneAssetCloneOptions

Configures application-defined node and material cloning when a SceneAsset contains types outside Mu3D's built-in scene model.

SceneInstance

Owns one mutable realization of a SceneAsset that can be attached to an application scene hierarchy.

Interfaces

IEncodedImageDecoder

Decodes encoded raster images for asset import without exposing a platform or native codec. Color images return unpremultiplied linear-light pixels with an explicit source color space; data images return normalized channels that have not undergone a color transfer transform.

IEncodedTextureTranscoder

Optionally transcodes an encoded texture container into an immutable GPU-ready compressed mip chain without exposing a native transcoder or container parser to Mu3D Core.
