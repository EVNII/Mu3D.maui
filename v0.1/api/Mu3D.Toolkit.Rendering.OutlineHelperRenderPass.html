Remarks

The pass rasterizes only the target into private mask/depth attachments, then composites the outer mask edge into the existing HDR color target. It does not add duplicate scene geometry, perform image encoding, or transfer pixels through the CPU. Targets outside the context scene contribute nothing, and each target mesh follows the context camera's visibility layers.
