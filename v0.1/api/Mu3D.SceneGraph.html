Camera

Base class for a transformable FP32 scene camera.

CompressedMaterialTexture

Stores an immutable backend-independent compressed two-dimensional material texture and its contiguous mip prefix. Container metadata and transcoder handles are deliberately excluded.

CompressedTextureMipLevel

Stores one immutable, tightly packed mip level of a compressed material texture.

DirectionalLight

Represents a transformable directional light. Its local negative Z axis is the direction in which light rays travel; translation does not affect directional lighting.

EquirectangularHdrEnvironment

Stores an immutable latitude-longitude HDR environment in an explicit linear-light RGB space. Pixel values are scene-referred RGB radiance samples in row-major order; negative and above-one components are preserved without tone mapping, gamut mapping or clipping.

HdrEnvironmentConverter

Converts explicitly tagged latitude-longitude HDR environments into deterministic cube maps. Filtering is performed in linear light. The horizontal longitude seam wraps and the poles clamp; the conversion performs no gamut mapping, tone mapping or clipping.

HdrEnvironmentCube

Stores an immutable square, six-face HDR environment cube in an explicit linear-light RGB space. Pixels are face-major in EnvironmentCubeFace order and row-major within each face. FP32 negative and above-one components are retained without clipping or tone mapping.

ImageBasedLight

Represents a transformable image-based light source. Rotation controls environment orientation; translation has no lighting effect. The current renderer provides diffuse irradiance and roughness-filtered split-sum GGX specular reflection.

Material

Base class for renderer materials. Concrete materials must give every color property an explicit working-space identity rather than treating untagged RGB values as display colors.

MaterialVariantManifest

Contains the de-duplicated material variants actually referenced by an asset or scene. It is a compile manifest, not the Cartesian product of every feature permitted by a template.

Mesh

Associates immutable geometry and a material with a transformable scene node.

MeshGeometry

Stores immutable indexed triangle geometry in backend-independent FP32 form.

MeshPrimitives

Creates immutable backend-independent geometry for standard 3D primitives.

MetallicRoughnessMaterial

Compatibility name for PbrMaterial. New code should use PbrMaterial to reflect that metallic/roughness is the base closure and clearcoat, sheen, transmission, volume, anisotropy and emission are composable extension blocks.

MorphTarget

Stores immutable FP32 local-space vertex deltas for one morph target.

MorphWeightAnimationTrack

Animates all morph-target weights on one mesh with immutable FP32 keys.

NormalizedRgbaDataImage

Stores immutable normalized RGBA data that must not undergo a color-space or transfer-function transform. Typical uses include normal and packed material-property maps.

OpenPbrGraph

OpenPbrGraphEvaluator

OpenPbrMaterial

OpenPbrPreviewResult

OpenPbrSurface

OpenPbrTexture

PbrIridescenceBlock

Provides the thin-film iridescence extension block of a PbrMaterial.

PbrMaterial

Represents a metallic/roughness material. Base color is explicitly tagged, unpremultiplied linear-light RGBA. Optional dielectric transmission and volume absorption remain scene-linear.

PbrSheenBlock

Provides the cloth/fiber sheen extension block of a PbrMaterial.

PbrSpecularBlock

Provides dielectric specular strength and F0 tint controls.

PbrTransmissionBlock

Provides transmission and its optional finite-volume block.

PerspectiveCamera

Represents a right-handed perspective camera with a zero-to-one depth range.

PointLight

Represents an isotropic point light. Intensity is luminous intensity in candela and physical illumination follows inverse-square distance attenuation.

PrefilteredEnvironmentCube

Stores an immutable roughness-ordered mip chain of scene-linear specular environment cubes. Mip zero represents roughness zero and the final mip represents roughness one.

PunctualLight

Represents shared color, intensity, and transform state for a punctual light.

QuaternionAnimationTrack

RadianceHdrEnvironmentAsset

RadianceHdrEnvironmentLoader

RadianceHdrReader

Decodes a Radiance RGBE latitude-longitude image into explicitly tagged linear FP32 RGB.

RadianceHdrSourceCache

Stores bounded encoded Radiance HDR sources under exact application-defined keys. The cache is application owned; clearing or discarding it never invalidates already decoded environments.

Scene
