Namespace Mu3D.Color

Classes

Cie2015Observers

Provides pinned CIE 170-2:2015 2° and 10° XYZ color-matching functions.

ColorSpaceReference

Base identity for a color space. Future ICC-backed references can extend this type without changing color-bearing material or image properties.

ColorViewProgram

Contains a portable FP32 evaluator and its immutable lookup resources, generated from OCIO 2.5.2. The original AgX LUT uses tetrahedral interpolation; ACES 2.0 uses its analytic transform and hue tables.

ColorViewTransform

Applies pinned official AgX, Filmic or ACES 2.0 display rendering to scene-linear RGB. Output is unpremultiplied display-linear sRGB, with one equal to ReferenceWhiteNits. Exposure precedes the view; alpha is preserved. No PQ, HLG or sRGB encoding is returned.

HdrTransferFunctions

Evaluates nominal-range PQ and HLG transfer functions from ITU-R BT.2100-3.

IccBlackPointEstimator

Estimates media-relative RGB ICC profile black points for black-point compensation.

IccLinearToRgbTransform

Converts a standard linear-light working-space color through one selected ICC PCS-to-device transform into explicitly profile-tagged encoded RGB components.

IccLinearToRgbTransformCache

Stores a bounded least-recently-used set of ICC linear-to-RGB output transforms.

IccMatrixTrcTransform

Applies the media-relative colorimetric device-to-PCS transform of an RGB ICC v2/v4 matrix/TRC profile and converts the resulting XYZ D50 value to a standard linear working space.

IccProfile

Stores an immutable validated ICC v2/v4 profile payload and its header identity without interpreting profile transforms.

IccProfileLinkTransform

Links one RGB ICC source profile to one RGB ICC target profile through PCS XYZ D50.

IccProfileLinkTransformCache

Stores a bounded least-recently-used set of compiled ICC profile-link transforms.

IccRgbToLinearTransform

Converts encoded RGB samples through one selected ICC device-to-PCS transform and then into a standard linear-light working space.

IccRgbToLinearTransformCache

Stores a bounded least-recently-used set of ICC RGB-to-linear input transforms.

IccSoftProofOptions

Specifies ICC proof and display intents, black-point compensation and encoded range policy.

IccSoftProofTransform

Compiles an immutable RGB ICC soft-proof chain with absolute proof-media simulation.

LinearRgbImageComparer

Compares explicitly tagged linear-light RGB images without tone or gamut mapping.

LinearRgbLut1D

Immutable per-channel FP32 shaper table in explicit linear-light spaces. Each RGB column is sampled independently; this table cannot represent cross-channel gamut conversion by itself.

LinearRgbLut3D

Immutable, bounded FP32 RGB cube with trilinear interpolation. Input/output color identities, HDR domain and out-of-domain behavior are explicit; alpha is copied unchanged.

LinearRgbaImage

Stores an immutable two-dimensional FP32 image with unpremultiplied linear-light RGBA pixels and one explicit color-space identity.

SpectralIntegrator

Integrates measured spectra against explicit color-matching functions.

SpectralObserver

Stores immutable experimental XYZ color-matching curves and observer provenance.

SpectralPowerDistribution

Stores an immutable, uniformly sampled nonnegative spectrum with explicit units and provenance.

SpectralRgbDisplayModel

Models a linear additive display using the measured SPDs of its three unit-drive primaries.

StandardColorSpaces

Provides shared identities for built-in linear RGB working spaces.

StandardLinearRgbConverter

Converts unpremultiplied linear-light RGB values between Mu3D's standard parametric RGB spaces. Conversion preserves negative and above-one components and does not perform gamut mapping, tone mapping or clipping.

StandardRgbColorSpaceReference

Identifies one built-in standard linear RGB working space.

StandardRgbEncodingConverter

Decodes standard RGB before rendering and encodes explicitly selected RGB outputs.

StandardRgbProfiles

Provides deterministic ICC v4 matrix/TRC profiles for standard encoded RGB interchange.
