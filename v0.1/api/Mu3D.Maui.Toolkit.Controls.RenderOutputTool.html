Remarks

The toolbar uses the shared per-viewport ViewportOverlay manager, so native layout, scrolling and accessibility move with the viewport while HDR scene rendering remains GPU-native. Output identity stays independent of scene visibility masks and render-pass ordering. Built-in values use RenderOutputIds; extensions may add explicitly registered identifiers through Items. Disabling or detaching restores the prior view output only while the tool still owns the value, so a later application assignment is never overwritten.
