Remarks

The tester projects every enabled operation's deterministic axis segments, rotation rings, and uniform-scale center through the supplied perspective camera. Scale handles always follow the target-local axes. Endpoint markers rank ahead of overlapping axis lines so mixed translate/scale handles remain selectable. It does not acquire raw input, capture pointers, rank scene objects, begin an interaction, or own the gizmo, target, or camera. Rotation rings use a fixed tessellation shared by every call; this class allocates only the accepted result.
