Selects the RGB blend function applied before source-over alpha compositing in linear light. Functions extend algebraically to negative and above-one values without clipping.

public enum CanvasBlendMode

Fields

Add = 3

Adds source and backdrop RGB in the overlap; alpha still uses source-over.

Multiply = 1

Multiplies source and backdrop RGB component by component.

Normal = 0

Uses the source RGB unchanged.

Screen = 2

Uses source plus backdrop minus their componentwise product.
