Identifies optional physically based lighting blocks compiled for a material.

[Flags]
public enum PbrMaterialExtensions

Fields

All = Emissive | Clearcoat | Anisotropy | Transmission | Volume | Sheen | Iridescence | Specular | DiffuseTransmission | Dispersion

Enables every currently supported optional PBR block.

Anisotropy = 4

Adds anisotropic base-specular response.

Clearcoat = 2

Adds the outer dielectric clearcoat layer.

DiffuseTransmission = 256

Adds diffuse transmission through a thin dielectric surface.

Dispersion = 512

Adds wavelength-dependent dispersion to finite-volume transmission.

Emissive = 1

Adds scene-linear emission.

Iridescence = 64

Adds wavelength-dependent thin-film iridescence to the base specular interface.

None = 0

Uses only the metallic/roughness base closure.

Sheen = 32

Adds the cloth/fiber sheen layer.

Specular = 128

Modulates dielectric specular strength and F0 color.

Transmission = 8

Adds dielectric surface transmission.

Volume = 16

Adds finite-volume thickness and absorption to transmission.
