Remarks

The toolbar is hosted by the viewport's shared ViewportOverlay manager. It observes and operates the assigned playable but owns no clock, animation evaluation, glTF object, scene resource or navigation lifetime. Applications may therefore use the same control with clip players, camera paths, MAUI animation bridges or custom timelines.
