Remarks

A non-null attachment policy declares that the pass writes and preserves that shared attachment. Loading additionally declares an input dependency on an earlier pass or initialized caller-owned content. This initial composition contract is deliberately scene-linear; it performs no implicit display encoding, gamut mapping, tone mapping, or clipping.
