Remarks

Left-button and direct one-finger drag pan across the world-up plane; right-button, native trackpad two-finger drag and direct two-finger drag rotate around the target; pinch and supported pointer wheels dolly. NavigationCommand provides focus-independent discrete navigation, while the optional focused hardware-key adapter can supply the same rotate/dolly actions. Map changes only declarative Orbit defaults; it does not introduce a separate input or controller implementation.
