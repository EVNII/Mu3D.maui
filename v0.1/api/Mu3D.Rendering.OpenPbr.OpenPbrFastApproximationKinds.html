Identifies the documented approximations Fast mode applies to one surface.

[Flags]
public enum OpenPbrFastApproximationKinds

Fields

BakedGraphTextures = 16

Connected inputs are baked to mipmapped textures sampled with hardware filtering and repeat addressing.

Reference modes evaluate the graph per texel with level-zero nearest/bilinear and explicit periodic/clamp/mirror addressing. Baking fixes the result onto the UV unit square at the largest connected source resolution, so clamp/mirror behavior outside that square and magnification above the bake resolution follow the baked texture instead of the source texels.

CoatEnvironmentBaseGgxChain = 2

The coat lobe's environment contribution uses the base GGX chain at coat roughness.

FuzzEnvironmentCharlieChain = 1

The fuzz lobe's environment contribution uses the Charlie sheen chain and its directional-albedo table.

Direct punctual lighting still evaluates the pinned fuzz closure.

None = 0

The surface's active inputs match the reference modes' lobe set.

SubsurfaceDropped = 4

The subsurface lobe is dropped entirely; its weight does not scatter or tint any term.

ThinFilmDropped = 8

The thin-film lobe is dropped entirely; its iridescence does not modulate any term.

Remarks

Every approximation is explicit and reported; nothing is silently dropped. Base specular, diffuse and coat environment terms always use the split-sum prefiltered chains by definition of the mode and are not individually flagged. See Fast.
