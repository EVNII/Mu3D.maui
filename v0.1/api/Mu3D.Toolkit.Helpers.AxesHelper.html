Remarks

The helper borrows an optional orientation target and camera only while calculating a frame or hit test. It owns no scene node, input source, camera controller, renderer, or native resource. Layout calculations reevaluate the current camera and borrowed target without retaining a previous projection. The explicit target supplies orientation independently of scene membership or visibility.
