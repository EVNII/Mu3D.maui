LoadAsync(Stream, GltfAssetLoadOptions?, CancellationToken)

Asynchronously reads and imports one JSON glTF or binary GLB stream. The caller retains ownership of source and the stream remains open after completion, cancellation or failure.

public static Task<GltfAsset> LoadAsync(Stream source, GltfAssetLoadOptions? options = null, CancellationToken cancellationToken = default)

Parameters

source Stream

A readable stream positioned at the start of the glTF source.

options GltfAssetLoadOptions

Optional limits, cache, source-retention policy and import services.

cancellationToken CancellationToken

Cancels stream reading and cooperative import work.

Returns

Task<GltfAsset>

The imported backend-independent asset.

Exceptions

ArgumentException

The stream is not readable.

ArgumentOutOfRangeException

A byte limit is not positive or the source-retention mode is invalid.

InvalidDataException

A source exceeds its configured limit or an external resource cannot be resolved.
