Remarks

Immutable geometry and decoded or compressed texture sources are shared. Nodes, transforms, materials, skins, morph weights and animation targets are cloned for every instance. The asset never owns a renderer, presentation surface or native GPU resource, so an instance can be reparented between application scenes and scene views.
