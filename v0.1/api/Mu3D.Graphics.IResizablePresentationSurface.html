Represents a configured presentation surface whose physical-pixel extent can be updated by a platform host.

public interface IResizablePresentationSurface

Remarks

A host can report layout changes from its UI thread while presentation occurs on another thread. Implementations must serialize or safely queue Resize(uint, uint) with presentation work.
