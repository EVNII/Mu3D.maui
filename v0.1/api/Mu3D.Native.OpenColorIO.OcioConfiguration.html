Remarks

No process-global OCIO configuration is selected or modified. Context variables use the configuration's declared defaults; process environment overrides and active display/view filters are not used by this API. Files and referenced LUTs remain application-owned. Loading a new configuration is an explicit operation.

Remarks

The declared output must match the view and share the destination's OCIO reference-space type. This avoids silently applying an inverse view transform while decoding. The caller must ensure the chosen destination is linear; OCIO names/encoding metadata alone do not prove linearity.
