Remarks

This pass is always an overlay: it loads prior HDR-linear color and uses no depth attachment. It owns graphics resources and numeric staging, and performs no input acquisition or camera mutation. Bounded value-only handle and vertex staging is reused while reevaluating the current helper, camera, orientation target and physical output extent. Disposal releases that staging capacity.
