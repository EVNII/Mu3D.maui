Remarks

The control composes the low-level Mu3DView, owns its automatic presentation session, follows the physical output extent, and releases renderer/depth resources before the session is invalidated. Scene objects remain application-owned and mutable; call InvalidateScene() after mutating them. An explicitly assigned RenderPipeline is borrowed and replaces the default one-pass scene pipeline. Use Mu3DView directly for custom draw commands or manual swapchain ownership.

Remarks

Null preserves scene-linear presentation, optionally scaled by SceneLinearExposureStops. Selecting a view uses an owned FP16 intermediate, or FP32 when the output is FP32. HDR presets require HDR extended-linear sRGB presentation. Custom passes must produce premultiplied scene-linear RGB, as the default scene and OpenPBR passes do. Display changes do not reset application-owned progressive accumulation.

SceneLinearExposureStops

Gets or sets scene-linear exposure from -32 through +32 stops. Defaults to zero.

public float SceneLinearExposureStops { get; set; }

Property Value

float

Remarks

Applies only when DisplayTransform is null. Non-zero exposure requires an extended-linear HDR Float16 or Float32 presentation target; SDR output is rejected explicitly. The final RGB is multiplied by 2 raised to this value, without tone mapping or changing alpha. Zero retains the direct presentation path without an extra pass. Exposure changes request a frame without changing scene lighting or resetting application-owned progressive accumulation. When a display view is attached, use ExposureStops instead.
