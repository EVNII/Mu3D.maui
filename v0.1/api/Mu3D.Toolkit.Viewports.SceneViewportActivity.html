Enum SceneViewportActivity

Namespace
Mu3D.Toolkit.Viewports
Assembly
Mu3D.Toolkit.dll

Describes the application-requested lifecycle level for one virtualized scene item.

public enum SceneViewportActivity

Fields

Active = 0

Load content when needed and own a live viewport while the host is loaded.

Suspended = 1

Release the live viewport while retaining already loaded managed scene content.

Unloaded = 2

Release both the live viewport and the control-owned scene content.

Remarks

Visibility discovery and the size of each range remain application policy. A virtualized UI normally marks visible items Active, a bounded nearby range Suspended, and every colder item Unloaded.
