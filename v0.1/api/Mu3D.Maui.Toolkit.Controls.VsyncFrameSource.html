Drives a per-frame callback at the display's native refresh rate for continuous viewport rendering. On iOS and Mac Catalyst the source owns a CADisplayLink whose PreferredFrameRateRange follows the window screen's MaximumFramesPerSecond, so ProMotion displays are not capped at MAUI's 60 Hz default ticker. Other platforms use the MAUI VSync animation service, which already follows the display.

Remarks

The application still owns scheduling policy: start the source while a continuously animated view is visible and stop it when the view hides or pauses. iPhone apps also need the CADisableMinimumFrameDurationOnPhone Info.plist opt-in before iOS lifts the system 60 Hz clamp. The source is not thread-safe; call it from the UI thread. The callback runs on the UI thread at display rate.
