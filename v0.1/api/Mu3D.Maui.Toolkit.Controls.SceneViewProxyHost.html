Remarks

Every proxy remains a GPU-native presentation output in the MAUI visual hierarchy without GPU readback or image encoding. Opaque proxies use direct HDR Surfaces; transparent proxies use the platform compositor's alpha carrier and retain HDR where that carrier supports it. The hidden bootstrap view owns the default device lifecycle; compatible proxy sessions borrow that device and own only their individual output.
