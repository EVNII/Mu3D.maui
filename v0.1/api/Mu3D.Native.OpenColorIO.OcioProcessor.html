Remarks

This is an explicit metadata assertion, not transfer decoding. Never use it for encoded display/view output. Use an explicit decode first, then bake with LinearRgbLut3D.Bake using a chosen domain/range policy. The adapter borrows this processor, which must remain alive while evaluating or baking it.
