# Official color view resources

AgX data is copied unchanged from Blender 5.0.0, commit
`a37564c4df7a9b604809e5192918400e46a0205f`, under
`release/datafiles/colormanagement`. It is credited in that configuration to
Troy James Sobotka, Zijun Eary Zhou, Mark Faderbauer, and Sakari Kapanen.
`BLENDER-LICENSE` preserves the OpenColorIO data license explicitly referenced by
the configuration. Blender renamed that file from `release/text/ocio-license.txt`
to `release/license/OpenColorIO.txt`, then consolidated it into release licensing
in commit `0a4dbc57b80fec06b740e66f3846951e886aa735`. The preserved text comes from
the preceding commit `65762c880fcbff57a273bf0fb18a6150d2eef652`.

ACES 2.0 and the scalar/vector shader operations are generated by OpenColorIO
2.5.2, commit `c52966a6677723d5bd2dbef0ccec3fed9cbc3790`. See `OCIO-LICENSE`.
The ACES preset uses the official `cg-config-v4.0.0_aces-v2.0_ocio-v2.5`
built-in transforms. AgX uses the original 57-cube data and tetrahedral lookup;
ACES uses the full analytic output transform and its original hue/cusp tables.
No fitted ACES filmic approximation or uniformly baked replacement is used.

Filmic uses that same pinned Blender configuration's Filmic sRGB base view (no
additional Look), original filmic_desat_33.cube and filmic_to_0-70_1-03.spi1d.
Its attribution to Troy James Sobotka and contributors is retained in the config.
It is an SDR transform; no Filmic HDR preset is inferred from its HDR scene input.

Generated C# translates the emitted HLSL's scalar/vector arithmetic, constructor
syntax, local names and texture fetches. Generated WGSL is compiled from the same
HLSL, with explicit storage-buffer fetches replacing texture access. Tables retain
the exact FP32 values exported by OCIO, including its HDR HLG decode lookup.
These are Mu3D adaptations; the upstream authors do not endorse Mu3D.

Source hashes, maintainer tools and regeneration instructions are maintained in
`eng/color-management`. Applications consume the committed managed code and data;
they do not run Python, OCIO, Slang, or downloads during their builds.
