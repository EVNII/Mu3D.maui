# Mu3D.Native.Ktx.Runtime

Runtime-only native assets for the optional Mu3D KTX2/BasisU adapter. Applications normally
reference `Mu3D.Native.Ktx`, which selects this exact runtime package transitively.

The package contains no Mu3D managed assembly, symbols, SourceLink data or source code. Native
assets are pinned to Khronos libktx v4.4.2 at commit
`4d6fc70eaf62ad0558e63e8d97eb9766118327a6`.
