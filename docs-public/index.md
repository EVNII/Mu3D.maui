# Mu3D

Mu3D is an HDR-first 3D renderer for .NET MAUI. Rendering, colors, transforms and cameras retain
FP32 semantics; normal HDR attachments use FP16, and no path silently applies SDR tone mapping.

This versioned preview contains guides for every Gallery feature and API reference generated from
reviewed Release assemblies plus their XML documentation. Start with the
[XAML component catalog](articles/xaml-components.md), continue with the
[Gallery overview](articles/features/gallery-overview.md), open a feature's Docs action from the
sample application, or browse the [API reference](api.md).
